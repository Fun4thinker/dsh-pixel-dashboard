# dsh-pixel-dashboard

> 给 [DSH（DeepSeek Harness）](https://github.com/deepseek-harness) 加一块**用量与费用看板**：
> 花了多少、花在哪、还剩多少，一页看完。
>
> - **多厂商计价**：内置 **8 家 / 43 条**官方价目（DeepSeek、智谱 GLM、阿里千问、OpenAI、
>   Anthropic、Google Gemini、xAI Grok、MiniMax），支持**自己补价**与**按提供商加价倍率**
>   （第三方中转也算得准）；认不出的模型只统计用量，绝不按别家的价硬算。
>   没收录的厂商（Kimi、豆包、Mistral 等）如实说明原因，并给出用自定义单价补价的路径。
> - **会话里直接看钱**：输入框下方一枚费用条，会话顶部多一个「费用」标签页——按模型、
>   按天、按峰谷把这条会话拆给你看。
> - **账户与套餐**：现金余额只查 DeepSeek 官方；智谱 / Command Code / 火山方舟 / Codex /
>   Cursor / Opencode 六家订阅额度一页切换查看。
> - **不改产品配色**：深色 / 浅色、背景、按钮全部保持 DSH 原版，插件只在自己那一页用色。

## 三块界面，各回答一个问题

| 界面 | 回答什么 |
|---|---|
| 侧栏「用量看板」整页 | **整体**：这个月花了多少、量花在哪、哪条会话最贵 |
| 会话顶部「费用」标签页 | **这一条**：本次会话的逐模型明细、逐日花费、当前账户还剩多少 |
| 输入框下方费用条 | **此刻**：本次会话已花多少钱，以及当前模型来源对应的余额 / 额度 |

侧栏那一行还会一直显示**现在是高峰还是空闲、还有多久切换**，不打开看板也能看到：

```
[▮] 用量看板        2时15分后空闲期     ← 高峰中（红）
[▮] 用量看板        空闲期剩2时15分     ← 空闲中（绿）
```

## 安装

需要 Node ≥ 18。插件**没有第三方依赖**，也**不需要构建**——`lib/` 是随仓库提交的产物。

```bash
dsh plugin --profile web add dsh-pixel-dashboard
```

装完**重启一次 `dsh`**，再刷新浏览器页面。

<details>
<summary>其他安装方式与更新</summary>

**从 GitHub 安装**（与 npm 同一份代码）：

```bash
dsh plugin --profile web add github:Fun4thinker/dsh-pixel-dashboard
```

> `github:` 安装会把当时 main 指向的 commit 固化进 lockfile，之后远端更新**不会自动跟进**；
> 更新需要先移除再添加。npm 渠道可以在插件管理器里走标准更新动作，**推荐优先用 npm**。

**从本地源码安装**（改代码时用）：

```bash
git clone https://github.com/Fun4thinker/dsh-pixel-dashboard.git
cd dsh-pixel-dashboard
node tools/build.mjs                              # 产物写进根 lib/
node tools/install-official.mjs --profile web      # 建 link: 软链指向本地目录
```

之后每次 `node tools/build.mjs` 都即时生效（客户端改动刷新页面即可，宿主改动要重启 `dsh`）。

**换电脑**只需要重跑一次安装命令；想把用量历史带走，额外复制 `usage-ledger.jsonl`。

</details>

## 看板一页里有什么

从上到下按「先看结论、再看构成、最后看细节」排：

1. **四张概览卡** —— 累计 Token、窗口 Token、窗口费用、连续活跃天数
2. **账户与套餐** —— **标签页**，一次只显示一家：DeepSeek 官方（现金余额）＋ 已配置的订阅额度
   各家。没配过凭据的收进「添加厂商」，不占版面
3. **Token 趋势**（模型 / 供应商 / 构成，默认按模型）＋ **消费趋势**（逐日金额柱；
   勾选「我的单价」后与官方价**并列**再画一根）
4. **时段与计费** ＋ **活跃日历**（一年一格一天，悬停看当天请求 / 会话 / token / 消费估计）
5. **模型分布** ＋ **费用明细** —— 带消耗阈值（默认只统计 ≥ 1000 万 token 的模型）与
   「默认最近 5 款 / 展开全部」；每行有「补价」入口
6. **消费 Top 会话** —— 按花费排序的前 8 条，点标题直接进入那条会话

## 计费口径

**所有金额都是「按单价估算」，不是你的实际账单。** 单价默认取各厂商**官方**价目
（美元价目按可调汇率折成人民币），你可以给任意模型覆盖单价、也可以给某条提供商路由
设**加价倍率**——那是给第三方中转用的：它按 token 收你的钱，单价却常与官方不同。

高峰 = 周一至周五（**不含中国法定节假日**）9:00–12:00、14:00–18:00（北京时间）；
其余时段含全部周末与中国法定节假日全天都是空闲，空闲价 = 高峰价的一半（**只对分时定价的
厂商成立**，智谱等按量定价不分时，界面只显示一列价）。费用按**每条请求发生时刻**分档计价。

价目表里没有的模型标**「估算价」**（暂按 Flash 折算）——**这一点必须看得见**，
因为把别家模型按 DeepSeek 计价比认不出更糟。补价有两个入口：
看板 →「费用明细」每行的**补价**按钮，或「设置 → 单价」整页（按厂商分组、可搜索、
可整份导入 / 导出 JSON、可改汇率与倍率）。

单价表、token 缩略规则（K / M / 亿）、「为什么一条 = 一个模型 + 一个提供商」，
以及补价的两种写法，见 **[docs/pricing.md](docs/pricing.md)**。

## 会话里的「费用」标签页

会话顶部（与「轨迹」「统计」并列）多一个**费用**页，它是费用条的**明细版**：

- 本次会话费用 + 高峰 / 空闲分档（含占比条）
- 用量构成：缓存命中 / 未命中 / 写入 / 输出，缓存命中率（分母是**计费输入**，
  没有输入时整行省略而不是显示 0%）
- **逐模型明细**：模型 / 提供商 / 三档 token / 单价·M / 金额，金额之和**严格等于**合计
- 逐日花费
- 当前模型来源对应的账户余额或套餐额度；取不到时显示「—」并写明原因，**绝不显示 0**

## 智能体团队

用 Agent Teams 派了 teammate 之后，费用条不再只看当前会话，而是显示**整队合计**；
点开详情按成员逐行列出各自金额与 token。

三条判定规则：**只有真的成团队才切口径**（成员 ≥ 2）；**成员归属只看会话自己的持久字段**
（父会话 id、递归深度），父会话被删时仍归到已知的团队并标出来；**不会重复计费**
（团队合计只用于费用条，看板总量仍按全部记录独立算一遍）。

## 账户与套餐

| 厂商 | 类型 | 窗口 | 凭据引用 |
|---|---|---|---|
| DeepSeek 官方 | **现金余额** | 余额 | `DEEPSEEK_API_KEY`（即 DSH 自己那把 Key） |
| 智谱 GLM Coding Plan | 订阅额度 | 5 小时、每周 | `ZHIPU_CODING_API_KEY` |
| Command Code | 订阅额度 | 5 小时、每周、每月 | `COMMAND_CODE_API_KEY`（可自动读 `~/.commandcode/auth.json`） |
| 火山方舟 | 订阅额度 | 5 小时、每周、每月 | `VOLC_ACCESS_KEY_ID` + `VOLC_SECRET_ACCESS_KEY` |
| Codex | 订阅额度 | 上游给的窗口长度 | `CODEX_ACCESS_TOKEN` + `CODEX_ACCOUNT_ID`（可自动读 `~/.codex/auth.json`） |
| Cursor | 订阅额度 | 计费周期 | `CURSOR_ACCESS_TOKEN`（可自动读 Cursor 的 `auth.json`） |
| Opencode | 订阅额度 | 每日 / 每月 | `OPENCODE_API_KEY` + `OPENCODE_WORKSPACE_ID`（可自动读 `~/.local/share/opencode/auth.json`） |

**没有凭据就没有额度可看**，这一点没什么可绕的；界面会直接告诉你这一家缺哪个引用名、
去哪拿、以及插件在这台机器上会去哪个路径找。**后六家都是未文档化的内部接口**，
可能随时失效——一家失败只标那一家，其余照常工作。

额度百分比怎么算、各家凭据往哪写（**火山要 AK/SK，不是 `ark-` 推理 Key；
Codex 要登录态 access token，不是 `sk-` 平台 Key**）、以及移除凭据的三种「删不掉」情形，
见 **[docs/account-and-plans.md](docs/account-and-plans.md)**。

## 通知

只保留**任务类**提醒：完成、失败 / 中断、等待授权 / 回答、子智能体进展、当前会话不打扰。
入口在**看板右上角「设置」→ 通知**（它不需要天天看，所以不占看板版面）。

**余额与套餐额度不再实时通知。** 那类提醒「低于阈值就一直提醒」，本质上是一个
你每次都要重新判断的动态量；现在改成在**会话标签页与输入框费用条里直接看**——
想知道的时候看一眼，而不是等它来打断你。

**主会话的「完成」与子智能体的「完成」不是一回事**：主会话跑完意思是模型输出完了、
可以继续推进；子智能体跑完只是**有个成员收工了**，所以它写作「有新进展」，
失败写作「未完成」，不会冒充「你的事完成了」。点通知会**切到那条会话**。

浏览器授权状态怎么区分、平台限制（点通知不会把窗口调到前台）见
**[docs/notifications.md](docs/notifications.md)**。

## 本机数据与隐私

| 事项 | 行为 |
|---|---|
| API Key | **不出本机**，只用于拼 `Authorization` 头；响应里只回报金额、币种与来源层名 |
| 余额请求 | 只发往 settings 里显式配置的 `baseURL`，否则官方 `https://api.deepseek.com`。**不读 `DEEPSEEK_BASE_URL`** |
| 套餐请求 | 只发往写死的官方域名，不接受改写 |
| 落盘 | 只写三份本机文件：用量账本 `usage-ledger.jsonl`、开关 `balance-prefs.json`、自定义单价 `custom-rates.json` |
| 移除凭据 | **只在你勾选并二次确认之后**才写，删的是 DSH 凭据文件里那几个引用名；插件不保留副本 |

用量账本默认在 `$DSH_HOME/plugins/dsh-pixel-dashboard/usage-ledger.jsonl`，按 `sessionId:seq`
去重，因此重复扫描不会让历史翻倍。无遥测、无自动上报、无外部依赖。
完整清单见 **[docs/data-and-privacy.md](docs/data-and-privacy.md)**。

## 常见问题

**装完没反应 / 页面没变化？** 重启一次 `dsh`，再强制刷新浏览器页面（**Ctrl/Cmd + Shift + R**）。

**为什么界面还是 DSH 原版配色？** 这是有意的：插件只给**看板整页**、**会话费用页**和
**费用条**上色，产品的深浅色与背景完全交还 DSH。

**金额和我的账单对不上？** 先确认口径：这里是「按单价估算」，不是账单。如果你走的是
第三方中转，请给它设**加价倍率**或给具体模型补价；如果你买的是订阅套餐，那它按积分 /
信用额计费，本来就不在这套按 token 的估算范围内。

**余额/额度显示「—」而不是数字？** 界面上会写明原因（没配凭据 / 请求失败 / 已关闭）。
把「不知道」显示成 `¥0` 会让人以为余额空了，所以这里不这么做。

**某家额度显示「不可用」？** 那一家取数失败了，原因写在同一块里。注意各家凭据互不通用
（见上表），且这些接口都是未文档化的。

**模型分布里怎么少了好几个模型？** 默认只统计达到阈值（1000 万 token）的模型，
其余的收在「另有 N 款未列出」里；点「展开全部」或去「设置 → 显示」调阈值即可。

**改了代码没生效？** 宿主半边改动要**重启 `dsh`**；只改客户端则刷新页面即可。

**怎么确认装好了、跑的是哪个版本？**

```bash
node tools/doctor.mjs --profile web
```

## 开发

```bash
node tools/verify.mjs                            # 构建 + 全套闸门（改完代码先跑这个）
node tools/build.mjs                             # 只重新构建产物到根 lib/
node tools/doctor.mjs --profile web              # 体检：装好没、跑的哪个版本、账本在哪
```

改代码时注意：**宿主半边（`lib/host.js`、路由）只在启动时加载，必须重启 `dsh`**；
客户端半边刷新页面即可。仓库内的 `AGENT.md`（不入库）记录了架构取舍与踩过的坑。
