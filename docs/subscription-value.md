# 套餐购买力

打开 **用量看板 → 账户与模型 → 套餐购买力**。默认以小卡显示当前周期：额度已用、已累计 API 等效金额、套餐购买力，卡底附有简短的换算说明。选中 Codex 且有正在进行的周额度时，默认看周；也可以切换到 5 小时等已观测窗口，或月账期。「对比」与「设置」点开才占空间。

## 怎么算

**API 按量付 $1 的购买力为 1×。套餐购买力 = 同一个周期内已累计的 API 等效金额 ÷ 套餐在整个周期的成本。**

例如一个 **$100** 的 30 天账期，当前周额度用了 **41%**，本机这周的用量相当于 **$127** 的 API 调用：

- 整个 7 天窗口的套餐成本是 `$100 × 7 ÷ 30 ≈ $23.33`。
- 本周已经达到 `$127 ÷ $23.33 ≈ 5.44×`，即套餐每付 **$1**，当前用出了约 **$5.44** 的 API 价值。
- **41% 只表示观测到的额度进度**，不拿来推算剩余额度的价值或放大金额，也不按已经过去的时间缩小成本。只要定价不变，当前窗口的 API 等效金额随使用累计，购买力也随之累计。

月账期直接用月费；短额度窗口按实际窗口长度和账期长度分摊。跨月账期时，分别按窗口在两个账期内所占的时间计算后相加。5 小时与周窗口覆盖的请求可以重叠，**不要把两个窗口的金额、成本或倍数相加**。

## 怎样对比

- **周期对比**：同一套餐、同长度窗口按购买力绘制；进行中的窗口和已结束的窗口分开标记。余额区、会话费用条成功读到 Codex 的长度、重置时刻和非零用量后才记录窗口，错过的窗口不推算。历史额度百分比若显示，指最后一次观测，不是最终值。其他提供商目前可以按月账期比较，不记录其额度窗口。
- **各套餐月均购买力**：统一用各自最近最多三个已结束的月账期比较。每个套餐独立计算 `纳入周期的 API 等效金额总和 ÷ 对应的套餐成本总和`，并显示纳入的样本数。未结束、缺价或数据不全的周期不进入均值；没有样本就显示 `—`。每个套餐的金额和费用先用同一币种，购买力倍数本身无单位。

## 配置和范围

1. 在「设置」选择套餐专用的 **DSH 提供商路由**（Codex 订阅插件通常是 `openai-codex`）；按量 API 及中转路由不能混入。同一路由如果切换账号，历史用量不能按账号拆开。
2. 填实际月费、币种（USD 或 CNY）和**要统计的首个账期开始日**。按北京时间 00:00、每月同日续费；当月没有这一天时取月底，下个月恢复原日期。
3. 若这个路由使用的就是「套餐余额」在查的 Codex 账号，可关联 Codex 额度，不需要重复录入凭据。

API 等效金额优先使用内置官方参考价，缺项才用「设置 → 模型单价」里显式补充的参考价；不使用其他模型兜底价。缓存和输出等分开计价，不计算未核验来源、继承的会话历史或本机账本未记录的用量。历史按当前月费、参考价和汇率回算，**不是实际账单、实际省下的钱或未来额度预测**。移除配置只移除本地设置和对应观测，不影响订阅、登录状态或账本。
